# Distribution build and validation

For the next local release (1.0.2), `npm run package` builds the versioned per-user NSIS installer and the portable ZIP in `release-build`. `npm run package:installer` and `npm run package:portable` build each format independently. The ZIP must be extracted to a writable directory; the marker file selects a `KartLink-data` profile alongside the executable. Windows protects the saved Playit credential for the Windows user and computer.

On 2026-11-04, before optimizing, the unpacked preview occupied 415.6 MiB and the self-extracting preview was 100.5 MiB. The baseline unpacked executable launched to its first interactive screen in 5529 ms, then 363 and 370 ms on two warm launches. This was a small local sample, not a controlled cold-start benchmark. Automated attachment to the old self-extracting wrapper timed out; its extraction time was not measured.

An Electron 39 development build removed build-time dependencies from the shipped app and excludes the unused `playit.exe`, leaving the room server and Playit daemon intact. The unpacked payload is 337.8 MiB; `app.asar` fell from 61.2 MiB to about 0.8 MiB. The installer is about 101.2 MiB, and the standard portable ZIP is about 135.2 MiB. These use different compression and are not directly comparable to the old self-extracting EXE. Electron itself remains the largest component. The ZIP avoids extracting the application on each launch.

Validation on this Windows PC: `npm test` (16 tests) and `npm run test:ui` (7 tests) passed. The bundled room was also exercised with two lightweight clients in two sessions on a separate local UDP port; this did not launch a game. An earlier packaged portable extraction launched in 4008, 323 and 330 ms, and an isolated installed copy launched in 934, 345 and 335 ms. These are small, differently warmed samples, not proof of a specific performance gain.

The final ZIP was extracted to a new temporary directory. Its executable used the adjacent `KartLink-data` and session directory; the installed build used its separate profile. Ctrl-plus, Ctrl-minus, Ctrl-wheel, reload and restart checks kept zoom at 100%; the application menu was absent. A test installer created the EXE, uninstaller, desktop shortcut and Start menu shortcut; its uninstaller removed the EXE, shortcuts and registry entry. Executable metadata reported KartLink P2P 1.0.2 and KartLink contributors, and the icon was inspected.

No separate clean Windows VM was available. The tests used isolated directories and profiles on the existing computer, not a clean OS. No public GitHub release was created. The earlier build used Electron 39, which had high-severity audit advisories. Electron was updated to 45.2.2 before release. The final Electron 45 build is 368.5 MiB unpacked, with a 119.4 MiB installer and a 155.6 MiB portable ZIP. Both packages were tested again using isolated directories and profiles; the Activity tab, zoom lock, portable profile, Windows metadata, installer shortcuts and uninstaller passed. The two packaged app payloads matched. Startup smoke timings included interaction and are not directly comparable to the earlier measurements. `npm audit` reported no high or critical findings, with 15 moderate findings in build dependencies.
